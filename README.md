# E-YOOSO X-39 Shortcuts & Macros

A collection of profiles, macros and tools for the **E-YOOSO X-39 Gaming Mouse**.

The goal of this project is to build high-quality productivity profiles for creative software instead of gaming.

Current focus:

* FL Studio (ver 1 done)
* Blender
* Photoshop
* Illustrator
* Premiere Pro
* Audition
* VS Code
* Windows
* Chrome

---

## Why?

The official X-39 software works, but creating macros manually is slow and there is virtually no community sharing profiles.

This repository aims to become a central place for reusable profiles, documented layouts and tools.
