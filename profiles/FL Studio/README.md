## Functions

| Button | Shortcut     | Action              |
| -----: | ------------ | ------------------- |
|      1 | F9           | Toggle Mixer        |
|      2 | F5           | Toggle Playlist     |
|      3 | F7           | Toggle Piano Roll   |
|      4 | F6           | Toggle Channel Rack |
|      5 | Ctrl+S       | Save Project        |
|      6 | Shift+F8     | Plugin Database     |
|      7 | Ctrl+Z       | Undo                |
|      8 | Ctrl+Shift+Z | Redo                |
|      9 | Space        | Play / Stop         |
|     10 | F12          | Close All Windows   |
|     11 | Alt+F8       | Browser             |
|     12 | F8           | Plugin Picker       |
